# Simulación: Impacto de Comisiones en FPV vs ETFs de Bajo Costo

Ejemplo práctico del efecto de las comisiones de administración en una inversión a largo plazo.

## Escenario

| Parámetro | Valor |
|-----------|-------|
| Aporte mensual | $1.000.000 COP |
| Horizonte | 15 años |
| Rentabilidad bruta | 15% anual |
| Comisión FPV | 3.5% anual |
| Comisión ETFs | 0.05% anual |

## Resultados

| Concepto | FPV (3.5%) | ETFs (0.05%) |
|----------|------------|--------------|
| Total aportado | $180.000.000 | $180.000.000 |
| Valor final | ~$476 millones | ~$665 millones |
| Ganancias | ~$297 millones | ~$485 millones |
| Diferencia | — | **+$189 millones** |

La comisión del 3.5% se come aproximadamente el **39% de las ganancias potenciales**.

## Notas tributarias (Colombia)

- **FPV**: Los aportes pueden ser renta exenta (con límites). Los retiros pueden estar exentos si se cumplen condiciones (10 años, pensión, vivienda, etc.).
- **BVC**: Las utilidades en venta de acciones listadas suelen estar exentas si no se supera el 3% de las acciones en circulación de la sociedad (Art. 36-1 ET).
- **eToro / plataformas extranjeras**: Las ganancias suelen tributar como ganancia ocasional al 15% si se mantienen ≥ 2 años.

Incluso pagando el 15%, la inversión de bajo costo suele superar al FPV con comisiones altas.
